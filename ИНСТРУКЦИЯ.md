# CopySnap - Инструкция по запуску

## Что это?

CopySnap - это готовый SaaS-сервис для AI-генерации контента. Пользователи платят подписку за доступ к инструментам копирайтинга на базе GPT-4o.

### Модель заработка:
- **Free**: 0 ₽ (5 генераций/день) — привлечение пользователей
- **Pro**: 990 ₽/мес (100 генераций/день)
- **Business**: 2 490 ₽/мес (безлимит)

**Цель**: 50 Pro + 15 Business = **~87 000 ₽/мес (~$950)**

## Что нужно сделать (один раз)

### Шаг 1: Получить API-ключи

1. **OpenAI API key** — зайди на https://platform.openai.com/api-keys, создай ключ
   - Стоимость: ~$0.15 за 1 миллион токенов (очень дёшево)
   - Доступ из РФ: через VPN при регистрации, потом работает через API без VPN

2. **ЮKassa** — зайди на https://yookassa.ru, зарегистрируйся как ИП/ООО/самозанятый
   - В настройках магазина найди **Shop ID** и **Секретный ключ**
   - Для тестирования используй тестовые ключи (доступны сразу)
   - Для боевых платежей нужно пройти модерацию (~1-3 дня)

### Шаг 2: Запустить setup-скрипт

```bash
# Убедись что Node.js 18+ установлен
node -v

# Запусти скрипт
./setup.sh
```

Скрипт попросит ввести ключи и всё настроит автоматически.

### Шаг 3: Запустить приложение

```bash
npm run dev
```

Открой http://localhost:3000 — готово!

### Шаг 4: Настроить webhook в ЮKassa

В личном кабинете ЮKassa:
1. Перейди в **Настройки** → **HTTP-уведомления**
2. Добавь URL: `https://твой-домен.com/api/payment/webhook`
3. Выбери событие: `payment.succeeded`

Без этого платежи будут проходить, но план не активируется автоматически.

## Как задеплоить (чтобы другие могли пользоваться)

### Вариант 1: VPS — Timeweb/Selectel/Hetzner (~300-500 ₽/мес)

Это лучший вариант для РФ — быстро, дёшево, полный контроль.

```bash
# На сервере:
git clone <твой-репозиторий>
cd copysnap
./setup.sh
npm run build
npm run start
```

Используй **nginx** как reverse proxy для порта 3000.
Настрой **SSL** через Let's Encrypt (бесплатно).

### Вариант 2: Railway (~$5/мес)

1. Зайди на https://railway.app
2. Создай проект из GitHub-репозитория
3. Добавь переменные окружения из файла `.env`
4. Railway сам задеплоит

## Структура проекта

Весь код структурирован и прокомментирован. Основные файлы:

- `src/app/page.tsx` — лендинг

- `src/app/api/payment/` — платежи через ЮKassa
- `src/lib/yookassa.ts` — клиент ЮKassa API
- `src/lib/auth.ts` — авторизация (JWT)
- `src/lib/openai.ts` — генерация контента
- `prisma/schema.prisma` — схема базы данных
